# FrameFind

FrameFind is an image-search application where users will be able to search for images by topic and view the results in a responsive grid.

I chose a dark green and cream colour palette to create a calm editorial look instead of copying the PixelPulse design.

I added quick-pick category chips so users can discover common search topics easily.

I also added a Clear button and an empty-state message to make the search interface easier to understand.
